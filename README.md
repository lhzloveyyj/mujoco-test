# 两连杆机械臂仿真

一个 MuJoCo 模型 + **MuJoCo 原生 3D 窗口** + 你自己的算法。

```
FK_IK/
├── models/
│   ├── README.md             # 目录约定:一个模型/部件一个文件夹,网格放各自的 assets/
│   ├── two_link_arm.xml      # 主模型:5 自由度手臂 + Robotiq 2F-85 夹爪 + 地面 + 目标点
│   └── grippers/robotiq_2f85/ # 夹爪部件:原版 XML + 8 个 STL + LICENSE + 说明
├── src/                      # 仿真程序,按职责分文件
│   ├── control.cpp           # ★ 你的算法(my_algorithm)    ← 平时只改这个
│   ├── control.hpp           # 控制接口声明 + 模型/关节说明
│   ├── robot.hpp             # 模型加载、步进、读状态(Sim)
│   ├── viewer.cpp            # 原生窗口:渲染、鼠标视角、信息面板
│   ├── viewer.hpp
│   └── main.cpp              # 入口:解析命令行、加载模型、开窗口
├── Makefile                  # make 编译
└── sim                       # 编译产物(可删,make 会重新生成)
```

## 跑起来

```bash
cd ~/workspace/mujoco_sim/FK_IK
make                      # 编译出 sim
./sim                     # 打开原生 3D 窗口,实时跑(默认)
./sim models/two_link_arm.xml 10   # [模型路径] [跑多少秒后自动退出]
```

窗口操作:

| 操作 | 作用 |
| --- | --- |
| 鼠标左键拖动 | 转视角 |
| 鼠标右键拖动 | 平移 |
| 滚轮 | 缩放 |
| 空格 | 暂停 / 继续 |
| M | 显示 / 隐藏底部的电机信息文字 |
| Esc 或关闭窗口 | 退出 |

窗口里能看到什么:

* 左上角实时显示 `t / 回转 / 肩 / 肘 / TCP 三维坐标 / 夹爪开度`;
* **每个关节处都有真实的电机几何体**:深灰色圆柱壳体 + 橙色转子法兰。
  壳体和法兰分别挂在"不转的一侧"和"跟着转的一侧"上,和真实机械臂一致
  (肩部壳体在底座上、肘部壳体在 link1 上);
* 夹爪掌部后面的深灰方块是夹爪的驱动电机;
* 左下角列出每个电机驱动的关节和它当前的出力(臂是 N·m,夹爪是 N)。

> 窗口里的文字只能用 ASCII —— MuJoCo 内置字体没有中文字形,写中文会变成方块,
> 所以界面上是英文,中文说明都在终端和这份 README 里。

机械臂的姿态由**你的算法**决定 —— 改 `src/control.cpp` 里的 `my_algorithm()` 再
`make && ./sim` 就能看到新效果。其余文件(模型封装、窗口、入口)不用动;
以后想换模型只改 `models/`,想改界面只改 `src/viewer.cpp`。

需要图形界面(它是个真窗口程序),所以在没有显示器的环境里跑不起来。

## 你的算法写在哪

**平时你只需要改 [src/control.cpp](src/control.cpp) 这一个文件**,里面就一个函数:

```cpp
static void my_algorithm(const mjModel* m, mjData* d, double t, double dt) {
  d->ctrl[0] = 0.5 * std::sin(2.0 * kPi * 0.10 * t);   // 回转    ← 换成你的算法
  d->ctrl[1] = -0.6 + 0.5 * std::sin(2.0 * kPi * 0.25 * t);   // 肩
  d->ctrl[2] = 1.2 + 0.6 * std::sin(2.0 * kPi * 0.25 * t);    // 肘
  d->ctrl[3] = kPi * std::sin(2.0 * kPi * 0.15 * t);          // 腕(绕小臂轴线)
  d->ctrl[4] = 127.5 * (1.0 - std::cos(2.0 * kPi * 0.5 * t)); // 夹爪 0~255
}
```

每个仿真步(2 ms)被调用一次:

| 你想做什么 | 读什么 | 写什么 |
| --- | --- | --- |
| 位置控制 | `d->qpos[0..4]` 五个关节角、`d->qvel` 角速度 | `d->ctrl[0..4]` 目标关节角(位置伺服去追) |
| 小臂/腕回转(对准工件) | `d->qpos[3]`、`d->qpos[4]` | `d->ctrl[3]`、`d->ctrl[4]`:绕小臂轴线转,不限位 |
| 控制夹爪开合 | `d->qpos[5..12]` 夹爪内部 8 个关节角 | `d->ctrl[5]`:**0 = 全开,255 = 闭紧**(想夹住东西给中间值) |
| 纯运动学(练 FK/IK) | `d->qpos` | `d->qpos[0..4]` 直接指定角度,机械臂立刻到位 |
| 力矩控制 | `d->qpos`、`d->qvel` | `d->qfrc_applied[0..4]` 关节力矩 |
| 读末端位置 | `d->site_xpos[3*ee]` = 抓取中心 TCP(两指之间,含 x/y/z) | — |
| 挪动目标点 | `d->mocap_pos[3*mocap]` | 同左(模型里那个绿圈就是它) |

文件开头的注释把这三类写法都列了例子,直接抄来改成你的算法即可。

## 模型

| 名字 | 说明 |
| --- | --- |
| `joint1_yaw` | 绕 **z** 轴回转(底座),`qpos[0]` |
| `joint2_shoulder` | 绕 **y** 轴俯仰(肩),`qpos[1]`,范围 -2.8 ~ 1.4 rad |
| `joint3_elbow` | 绕 **y** 轴俯仰(肘),`qpos[2]`,范围 ±2.9 rad |
| `joint4_forearm_pitch` | 绕 **y 轴俯仰**,在小臂中段(等于**第二个肘**,让小臂上下折),`qpos[3]`,范围 ±2.0 rad |
| `joint5_wrist_roll` | 绕 **小臂轴线**回转(法兰处,腕),`qpos[4]`,不限位。让夹爪绕杆转圈、改变张合方向,TCP 位置不动 |
| `motor_yaw` / `motor_shoulder` / `motor_elbow` / `motor_forearm` / `motor_wrist` | 五个位置伺服,`ctrl[0..4]` 是目标关节角 |
| 电机外形 | 每个关节一套:深灰圆柱壳体(挂近端、不跟着转)+ 橙色转子法兰(挂远端、跟着转)。腕部是一圈同轴套筒。都是真实几何体、带质量,不是标记物 |
| 夹爪 | **Robotiq 2F-85**(自适应两指夹爪):8 个关节组成两套四杆机构,由 1 个驱动器 `fingers_actuator` 通过肌腱 + equality 约束联动,所以开合只有 1 个自由度 |
| 夹爪控制 | `ctrl[4]`:**0 = 全开,255 = 闭紧**(指垫间距 98 mm → 15 mm,行程约 85 mm) |
| 夹爪网格 | `models/assets/` 里 8 个 STL,来自 MuJoCo Menagerie(BSD-3-Clause,ROS-Industrial),见同目录 `LICENSE` / `README.txt` |
| `site "ee"` | 末端标记,位于**两指之间的抓取中心 TCP**(`site_xpos` 可取世界坐标) |
| `body "target"` | 绿色的 mocap 目标点,可以随便挪 |
| `base` / `link1` / `link2` | 底座、连杆 1(0.5 m)、连杆 2(0.4 m) |

**5 自由度手臂**:底座回转(z 轴)+ 肩俯仰(y 轴)+ 肘俯仰(y 轴)+ **小臂中段俯仰**(y 轴,
相当于第二个肘)+ **腕回转**(绕小臂轴线,在法兰处)。

分工是:四个俯仰/回转关节负责把末端送到三维空间里的某个位置(小臂多一节,够得更远、也能
绕过障碍),腕回转负责把夹爪的张合方向转到位 —— 抓东西时先转腕对准工件,再闭合夹爪。

末端法兰上装着 Robotiq 2F-85 夹爪(从法兰再伸出 0.157 m)。
因为俯仰关节的轴不平行于重力方向,**重力会产生关节力矩** —— 位置伺服要一直出力把手臂撑住,
水平伸展时会有几毫米到几厘米的静差(真实机械臂也这样,想要更"硬"就把 `motor_shoulder` 的
`kp` 调大,或者自己在算法里做重力补偿)。伺服增益:回转 `kp=400`、肩 `kp=3000`、肘 `kp=1500`。
`site "ee"` 指的是**两指之间的抓取中心(TCP)**,不是小臂末端。

模型总共 13 个自由度(5 个臂关节 + 夹爪内部 8 个),夹爪闭紧时两片指垫会互相接触 ——
这是 Menagerie 原模型自带的行为,不是 bug。

## 依赖

* `g++`
* conda 里那份 mujoco 自带的 C 库(头文件 + `libmujoco.so`)—— Makefile 自动找,
  找不到就手动指定 `make MJ=/path/to/site-packages/mujoco`
* 系统的 GLFW(`libglfw3-dev`,原生窗口用)

排查用 `make check-env`。
